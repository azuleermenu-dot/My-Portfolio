# Asnor Ali — Personal Portfolio

A cinematic, editorial personal portfolio for **Asnor Ali**, a web developer and creative builder.

## Introduction

I'm Asnor, a web developer who learned by building.

This portfolio is a personal digital space for exploring my journey, projects, ideas, and approach to creating websites and digital experiences. My process is hands-on: I experiment, build, make mistakes, iterate, and keep improving.

I care about the intersection of **design, technology, and ideas** — creating experiences that feel intentional while keeping the underlying code clean, responsive, and maintainable.

## Design Direction

The portfolio intentionally avoids the typical developer-template look. It uses a mostly monochromatic palette, oversized typography, editorial composition, subtle motion, atmospheric visuals, and large project presentations to create a more personal digital experience.

## Development

This project uses React and Vite with a component-based structure and modern CSS. It is designed to remain lightweight and responsive without an unnecessary backend.

### Run locally

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
```
