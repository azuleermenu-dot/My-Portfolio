## 06 — DEVELOPMENT

Built with **React + Vite** and a component-based architecture.

The portfolio is intentionally lightweight: modern CSS, reusable components, responsive layouts, semantic HTML, accessible interactions, and no unnecessary backend.

```text
src/
├── components/
├── data/
├── styles/
├── App.jsx
└── main.jsx
```

### Run locally

```bash
npm install
npm run dev
```

### Production build

```bash
npm run build
```

### GitHub workflow

Changes are developed through branches and pull requests so improvements can be reviewed, tracked, and merged cleanly.
